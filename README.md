# Cyber Scripting Lab

Personal cybersecurity scripting lab focused on building practical automation skills in **PowerShell** and **Python**.

This repository contains scripts developed while learning and practicing core skills used in security operations, vulnerability management, patch management, and endpoint security.

---

## Purpose

The goal of this lab is to develop real, usable scripts that demonstrate:
- Endpoint and system inventory
- Security baseline / compliance checks
- Vulnerability and patch-related automation
- Log and report parsing
- Clean documentation and version control habits

---

## Repository Structure

cyber-scripting-lab/
├── powershell/          # PowerShell scripts
├── python/              # Python scripts
└── docs/                # Notes and documentation


---

## Projects

### PowerShell
- **Software Inventory** – Collects installed software and exports to CSV
- **Windows Update / Patch Status Checker** – Reports update and reboot status
- **Endpoint Compliance Checker** – Checks Defender, firewall, and basic security settings

### Python
- **Vulnerability CSV Parser** – Filters and prioritizes findings from scanner reports
- **CVE Tracker** – Pulls and highlights recent critical CVEs

*(Projects will be added and updated as they are completed.)*
